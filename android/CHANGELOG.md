# Overworld for Android — changelog

What changed in each release of Overworld for the AYN Thor, newest first.

## 0.2.0 — 2026-11-14

- Pokémon Emerald (US) now works out of the box, free, even from a brand-new
  save.
- Settings shows who each installed license belongs to.
- Fixes: the party count stays right through trainer battles, empty
  held-item slots no longer show an item name, and an imported license works
  at once instead of after a wait.
- Settings → Help → Send logs to the developer: when something goes wrong,
  send this device's logs with a note. You get a support code to paste in
  Discord or an email so the developer can find them. The page lists what is
  sent and what is removed or never collected, and Forget this device
  deletes it all.
- Overworld now keeps a short record on the Thor when it, the reader or the
  game screen crashes, so the logs you send say what happened. Nothing leaves
  the device unless you send it or join the beta.
- For 30 days after you send logs, the developer can ask for more. Overworld
  asks you first, with Send and Not now.
- Settings → Beta: join with a code from the developer to get test builds
  early. In the beta, crash details and requested logs are sent on their own.

## 0.1.0 — 2026-11-10

- First release. Overworld now runs on the Thor itself: start a game in
  RetroArch, open Overworld, and the companion fills the bottom screen. No
  computer needed.
- Finds your ROM on its own from RetroArch's history.
- Open a `.gdalic` licence from email or a file browser to unlock paid games.
- Checks for a new version once a day and offers to install it. Turn this off
  in Settings → Updates.
- Settings → Help: get help in the Overworld Discord, or email
  support@greatdesktopapps.com.

# Overworld for Android — changelog

What changed in each release of Overworld for the AYN Thor, newest first.

## 0.1.0 — 2026-11-10

- First release. Overworld now runs on the Thor itself: start a game in
  RetroArch, open Overworld, and the companion fills the bottom screen. No
  computer needed.
- Finds your ROM on its own from RetroArch's history.
- Open a `.gdalic` licence from email or a file browser to unlock paid games.
- Checks for a new version once a day and offers to install it. Turn this off
  in Settings → Updates.
- Settings → Help: get help in the Overworld Discord, or email
  support@greatdesktopapps.com.
